Файл базы данных SQLite (`app.db`) хранится в приватной директории приложения на устройстве пользователя. 

Таблица `notes` имеет следующую структуру:
- `id` - целочисленный первичный ключ с автоинкрементом
- `title` - текстовое поле для заголовка заметки (обязательное)
- `body` - текстовое поле для основного текста заметки (обязательное)
- `created_at` - целочисленное поле для времени создания в миллисекундах
- `updated_at` - целочисленное поле для времени последнего обновления

CREATE(Создание): При добавлении новой заметки создается объект Note с текущим временем в полях `created_at` и `updated_at`, затем вызывается метод `insertNote`, который преобразует объект в Map и выполняет SQL INSERT.

READ(Чтение): Метод `fetchNotes` выполняет SELECT запрос к таблице с сортировкой по дате создания (новые сверху). Результат преобразуется из Map в объекты Note и возвращается как список.

UPDATE(Обновление): При редактировании заметки создается копия объекта с обновленными полями и новым значением `updated_at`, затем выполняется SQL UPDATE по идентификатору записи.

DELETE(Удаление): Удаление происходит по идентификатору записи через SQL DELETE. Поддерживается два способа удаления - через иконку корзины и через свайп элемента списка.

Все операции выполняются асинхронно через Future, чтобы не блокировать пользовательский интерфейс.
