В данном коде использовались следующие основные виджеты Flutter:
1. MaterialApp - корневой виджет Material Design
2. Scaffold - каркас экрана с AppBar и body
3. AppBar - верхняя панель приложения
4. Column - вертикальное расположение дочерних элементов
5. Row - горизонтальное расположение иконок
6. Text - текстовые элементы с различным стилистическим оформлением
7. ElevatedButton - кнопка с возвышенным эффектом
8. Container - контейнер с заданными размерами и цветом фона
9. Icon - отображение иконок из Material Design
10. SizedBox - создание отступов между элементами
11. Center - выравнивание содержимого по центру

Цвета задавались несколькими способами:
Colors.blue и Colors.green - использование стандартных цветов Material Design
Color(0xFF2E7D32) - кастомный зеленый цвет через HEX-код с альфа-каналом
Color(0xFFFFA000) - кастомный оранжевый цвет
Colors.white - белый цвет для текста

Стили текста изменялись через параметры TextStyle:
fontSize - размер шрифта (24, 18, 16)
fontWeight - жирность (FontWeight.bold, FontWeight.w500)
color - цвет текста (белый, зеленый)
